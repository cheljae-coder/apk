GitHub Actions로 APK 설치파일 만들기 상세 안내

1. GitHub 저장소 생성
- github.com 접속
- New repository 선택
- 저장소 이름 예: InsuranceAnalyzerApp
- Public 또는 Private 선택
- Create repository 선택

2. 파일 업로드
- Add file > Upload files 선택
- 이 프로젝트 폴더 안의 모든 파일과 폴더를 업로드
- 중요: 폴더 자체가 아니라 폴더 안의 내용물이 루트에 올라가야 합니다.

정상 루트 예시:
settings.gradle
build.gradle
gradle.properties
app/
.github/
README.md

잘못된 예시:
InsuranceAnalyzer_GitHub_APK_Builder_Project/settings.gradle

3. Actions 실행
- 저장소 상단 Actions 선택
- 왼쪽에서 Build Android APK 선택
- Run workflow 클릭
- 초록색 완료 표시가 나올 때까지 대기

4. APK 다운로드
- 완료된 실행 항목 클릭
- 하단 Artifacts 확인
- insurance-analyzer-debug-apk 다운로드
- zip 압축 해제
- app-debug.apk 확인

5. 스마트폰 설치
- app-debug.apk를 스마트폰으로 전송
- 파일 관리자에서 APK 선택
- 알 수 없는 앱 설치 허용
- 설치 완료 후 보험보상 분석기 실행

6. 실패 시 확인할 것
- .github/workflows/build-apk.yml 파일이 있는지 확인
- app/src/main/assets/index.html 파일이 있는지 확인
- app/build.gradle 파일이 있는지 확인
- Actions 로그에서 빨간 오류 줄 확인

7. 가장 흔한 오류
- 저장소 루트가 한 단계 더 들어간 경우
- index.html이 assets 폴더에 없는 경우
- GitHub Actions가 비활성화된 경우
- Android SDK 설치 단계에서 네트워크 오류가 난 경우
