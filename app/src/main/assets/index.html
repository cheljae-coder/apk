INSURANCE CLAIM STRATEGY ANALYZER

보험 약관 정밀분석 및 청구전략 리포트 프로그램

보험금 액수를 계산하지 않고, 어떤 보험·특약을 청구해야 하는지, 약관의 어느 부분이 근거가 되는지, 준비서류와 지급거절 대응전략을 정리합니다.

단독 실행형 HTML분석 버튼 작동부를 외부 라이브러리와 분리한 안정형 버전

사건 기본 입력

처음에는 이 입력 화면만 표시됩니다. 1분 보상 분석하기를 누르면 입력 화면은 숨겨지고 자동분석 리포트만 표시됩니다.

농업인 전용 확인항목
농업경영체 등록 여부와 농업인 안전보험 가입 여부는 일반 생명보험·손해보험의 보험금 산정 항목이 아닙니다. 농업인 안전보험, 농기계종합보험, 국고·지자체 보험료 지원, 농작업성 입증 검토 때만 반영됩니다.
진단서 텍스트 기반 질병코드 자동입력

진단서 또는 의무기록 내용을 붙여넣으면 KCD/ICD 코드를 자동 추출합니다. 코드가 없으면 진단명 키워드로 대표 코드를 추정합니다.

자동추출 대기 중입니다.
분석자료 세부 입력 메뉴

진단서 외에 보험증권, 약관, 치료자료, 사고사실확인서, 보험사 안내문을 항목별로 넣으면 통합 분석합니다.

1. 사고 경위 및 발생장소 자료

초진기록지의 사고 경위, 사고 장소, 작업 내용, 교통사고 내용, 목격자 진술을 입력하십시오.

2. 보험가입자료·보험증권·특약자료

보험증권, 가입설계서, 특약명, 보험기간, 납입상태, 피보험자 정보를 입력하십시오.

3. 보험약관 원문·지급사유·면책조항 입력

약관의 보험금 지급사유, 지급하지 않는 사유, 장해분류표, 수술의 정의, 입원의 정의, 청구서류 조항을 붙여넣으십시오.

4. 치료·수술·입원·진료비 자료

수술기록지, 입퇴원확인서, 진료비 영수증, 진료비 세부내역서, 보존적 치료 여부를 입력하십시오.

5. 행정·산재·농업인 입증자료

농업경영체 등록확인서, 사고사실확인서, 119구급기록, 경찰기록, 산재 관련 자료, 농협 사고접수 내용을 입력하십시오.

6. 배상책임·화재·법률비용·교통사고 자료

상대방 과실, 차량번호, 화재·누수·대물피해, 형사합의, 벌금, 변호사선임비용 자료를 입력하십시오.

7. 보험사 안내·분쟁·기존 청구 이력

보험사의 부지급 안내, 삭감 사유, 손해사정 의견, 기존 청구 내역, 금융감독원 민원 검토 사항을 입력하십시오.

8. 추가 상담 메모·고객 진술

고객 진술, 추가 사실관계, 행정사가 확인한 쟁점을 입력하십시오.

9. 첨부파일 OCR·문서 파싱

TXT, CSV, JSON, MD, XML, HTML은 즉시 읽습니다. PDF, DOCX, HWPX, 이미지 OCR은 인터넷 연결 시 외부 파서를 동적으로 불러옵니다. 분석 버튼 작동과는 분리되어 있습니다.

선택된 파일이 없습니다.
문서 파싱 대기 중입니다.
운영 기준
이 프로그램은 “얼마를 받을 수 있다”가 아니라 “어떤 보험·특약을 청구해야 하는가, 어떤 약관 조항 후보가 있는가, 어떤 서류와 대응전략이 필요한가”를 판단합니다.

자동분석 리포트

리포트 화면에서는 입력 화면이 숨겨집니다. 새 사건을 입력하려면 아래 초기화 버튼을 누르십시오.

분석 대기

입력자료와 약관 문구를 대조 분석 중입니다

청구 가능 유형, 준비서류, 지급거절 대응전략, 행정사 수행사항을 정리하고 있습니다.

본 프로그램은 상담 준비용 선별 도구입니다. 실제 청구 및 분쟁 대응 시에는 보험증권, 약관 원문, 의무기록 원본, 사고 입증자료를 대조해야 합니다.
